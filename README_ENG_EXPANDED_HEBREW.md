
# README - פרויקט AI לחיזוי חומרת מחלת הקורונה

## סקירת הפרויקט
הפרויקט משווה בין גישות שונות לחיזוי חומרת מקרי COVID-19 בהתבסס על **נתונים קליניים טבלאיים (תסמינים, גיל, מגדר)** ועל **תמונות רנטגן של הריאות**. המחקר בודק האם מודלים מבוססי נתונים טבלאיים או מודלים מבוססי תמונות מספקים דיוק טוב יותר.

המודלים שנבדקו:

- **מודלים של למידת מכונה:** יער אקראי, רגרסיה לוגיסטית, עץ החלטה.

- **מודלים של למידה עמוקה:** רשת עצבית מלאכותית (ANN), CNN ולמידה מעברית (ResNet50).

## **מבנה הפרויקט**
📂 **data/** – מערכי נתונים מעובדים (טבלאיים + תמונות)  
📂 **models/** – מודלים מאומנים וקובצי תצורה  
📂 **notebooks/** – מחברות Jupyter לניתוח  
📂 **scripts/** – סקריפטים ב-Python לעיבוד נתונים ואימון מודלים  
📄 **requirements.txt** – תלותים נדרשים  
📄 **README.md** – תיעוד הפרויקט

## **התקנה והוראות הפעלה**

### **1. שכפול המאגר**
```bash
git clone https://github.com/matanlakker/BINA.git
cd BINA
```

### **2. התקנת החבילות הנדרשות**
```bash
pip install -r requirements.txt
```

### **3. עיבוד הנתונים**
```bash
python scripts/preprocess_data.py
```

### **4. אימון המודלים**
```bash
python scripts/train_model.py --model ResNet50
```

### **5. הערכת הביצועים**
```bash
python scripts/evaluate.py
```

## **תוצאות ביצועי המודלים**

### **מודלים מבוססי נתונים טבלאיים**
| מודל | דיוק | דיוק חיובי | רגישות |
|---|---|---|---|

### **מודלים מבוססי תמונות**

## **מסקנות והמלצות**
- **למידה מעברית (ResNet50) הציגה את הביצועים הטובים ביותר** בהשוואה למודלים אחרים.

- **מודלים מבוססי תמונות השיגו תוצאות טובות יותר באופן משמעותי** ממודלים מבוססי נתונים טבלאיים.

- **נדרשים מערכי נתונים גדולים יותר** כדי לשפר את הביצועים.
